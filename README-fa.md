# مدیریت کارهای روزانه

## اجرا در حالت توسعه

```powershell
npm.cmd install
npm.cmd start
```

کارها در حافظهٔ مرورگر برنامه ذخیره می‌شوند. برای هر کار می‌توان دسته و موعد تعیین کرد و فهرست را بر اساس دسته فیلتر کرد. اگر کار موعد داشته باشد، گزینهٔ «افزودن به تقویم» یک فایل استاندارد `.ics` می‌سازد و آن را با برنامهٔ تقویم پیش‌فرض ویندوز باز می‌کند.

Windows Calendar قدیمی دیگر پشتیبانی نمی‌شود. فایل ICS راهی برای افزودن رویداد به Outlook یا برنامهٔ سازگار است؛ این روش همگام‌سازی زنده و دوطرفه نیست.

## ساخت و انتشار نسخه

نسخه‌های ویندوز از GitHub Releases منتشر می‌شوند. گردش‌کار `.github/workflows/release.yml` هنگام push یک tag با پیشوند `v` نصب‌کننده می‌سازد.
## نسخهٔ 1.2.0
- دکمهٔ بررسی به‌روزرسانی کنار دکمهٔ خروج قرار گرفت.
- از تنظیمات می‌توان دسته‌های دلخواه ساخت و تقویم شمسی را برای نمایش موعدها روشن یا خاموش کرد.
- تقویم شمسی برای انتخاب موعد اضافه شد.
- پیام خطای به‌روزرسانی اکنون علت دقیق دریافتی از updater را نمایش می‌دهد.
